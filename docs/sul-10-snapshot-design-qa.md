## 확인 결과

- 글꼴: `OTW Snapshot Inter`, `OTW Snapshot Pretendard`가 적용되고 `data-snapshot-font-mode=web`, `data-snapshot-ready=true`였다. PNG에서도 한글과 숫자가 정상 표시된다.

- 색상: 피치 배경, 크림 패널, 코랄 날짜·시간, 세이지 칩과 일정 없음 영역을 사용한다. 다크 테마는 따뜻한 갈색 계열로 대응한다.
- 이미지: 기존 로고와 실제 멤버 WebP 프로필을 사용한다. 로고는 어두운 배경에서도 읽히도록 흰색 영역에 둔다.
- 내용: 2026-09-14 로컬 저장 일정의 방송 2건, 게릴라 2건, 미정 1건, 휴방 2건과 일정 없는 멤버 1명을 확인했다. 2026-09-16의 일정 없는 화면도 확인했다.
- 브라우저 콘솔: 검사 시 오류 없음. 데이터나 API 계약, 조회·정렬·그룹화 동작을 변경하지 않았다.

## 발견 및 수정 이력

1. **P2 / PNG 배경 불일치**: 최초 실제 다운로드에서 편성표의 피치 배경이 흰색으로 저장됐다. `toPng`에 전달한 배경이 스냅샷 노드가 아닌 문서 body의 색상이었다. 스냅샷 노드의 계산된 배경색을 사용하도록 수정했다. 같은 공개 UI 흐름으로 다시 다운로드하여 밝은 배경 RGB(246,223,204), 어두운 배경 RGB(33,30,28)를 실제 PNG 픽셀에서 확인했다.
2. **P2 / 다크 안내문 대비**: 세이지 배경에 기존 회색 안내문이 낮은 대비로 표시됐다. 해당 영역의 텍스트·아이콘에 전용 전경 토큰을 적용했다. 수정 후 브라우저에서 RGB(220,232,204)를 확인하고 하단 화면 및 실제 PNG를 다시 열어 검증했다.
