# OTW·LuvDia 현행 공개·보관 정책

기준: 2026-10-16, PR160/PR161 반영 소스. 현재 실행 순서와 D1 중단 조건은 [현재 작업](../current-work.md)이 소유한다. 과거 이관 설계·실행부는 현행 운영의 의존성이 아니다.

## 시각과 대상

- 전환 시각은 **2026-10-19 00:00:00 Asia/Seoul**, UTC로 2026-10-18T15:00:00Z다.
- 전환 전 LuvDia의 공개 HTML·콘텐츠 API·파일은 닫고 카운트다운을 표시한다. 정상 Clerk 관리자 로그인과 미리보기는 유지한다.
- 전환 후 LuvDia를 공개하며 기존 회원/관리자 권한과 양 사이트 계정·DB·R2 격리는 유지한다.
- OTW는 전환 후 bing_hayu, u_lili, yang_mei의 일반 노출과 신규 수집을 종료한다. 원본 보관·관리자 접근·비대상 멤버와 정당한 공유 자료는 보존한다.
- OTW D-day 숨김 대상은 운영자가 확정한 **ID 4·9·10·11**이다. 제목으로 새 관계를 추론하지 않는다.

## 실행과 보존 경계

서버 시간이 요청과 최종 저장을 판정한다. 시작 전 검사와 최종 소유 트랜잭션의 검사 모두 유지한다. 정각을 넘긴 수집 응답은 관련 쓰기 전체와 원자적으로 차단한다. 관리자·공유 자료 예외를 약화하지 않는다.

GET /api/publication-status의 opensAt, serverNow, phase, canPreview 계약을 유지한다. 공개 전 차단 응답의 no-store와 역할 경계, 직접 파일·HEAD·인코딩 경로도 같은 정책을 따른다. 브라우저 열린 탭/캐시는 서버 정책을 대신하지 않는다.

공개 정책·아카이브 선택·수집 차단·revision은 [content-access](../../worker/features/content-access/index.ts), 파일 참조·보호·보존·불명확한 업로드 복구는 [assets](../../worker/features/assets/index.ts), 과거 DTO는 [content-history](../../contracts/content-history.ts)가 소유한다. 과거 원본을 새 계정의 운영 이벤트로 재생성하지 않는다. [공통 시간 정책](../../contracts/site-publication.ts)도 유지한다.

0102~0140과 기존 테이블·데이터·제약조건은 보존한다. 0141의 이관 전용 트리거 제거는 이미 반영한 변경이며 다시 이관 실행부를 복원하지 않는다. 일반 파일 참조 규칙 9개와 기존 보호 20개는 유지한다. 실제 배포 증거와 검증 한계는 [반영 기록](../reports/sul-36/2026-10-16-content-transition-retirement.md)에 있다.

## 관측과 복구

기존 otw-luvdia-19 예약은 19일 00:01 KST에 결과를 관측한다. 이 예약은 전환 실행 주체가 아니다. D1 중단 지시가 유효하면 D1·사이트/API 확인을 보류하고 미확인으로 기록한다. 실제 관측 전에는 정각 전환 완료라고 판정하지 않는다.

실패 시 공개 정책과 schema141에 호환되는 버전만 복구 후보로 삼는다. 정책 도입 전 Worker로 되돌려 OTW 자료를 다시 노출하거나 데이터를 지우는 롤백을 하지 않는다. 기존 Cron·Queue·retry·DLQ와 의도적 자동화 중지는 관측 목적으로 변경하지 않는다.
