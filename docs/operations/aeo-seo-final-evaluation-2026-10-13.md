# AEO·SEO 최종 평가 (2026-10-13)

## 결론

**기술 기반은 양호하고 실제 웹 검색·AI 검색 노출도 있지만, 검색 노출 확대와
사이트맵 정상 처리가 완료된 상태는 아니다.**

사용자 요청에 따라 사이트맵 예약 점검 `otw`를 삭제했다. 삭제 도구의
`deleteStatus: deleted`와 해당 설정 파일·디렉터리 부재를 확인했다.
사이트맵 성공으로 종료한 것이 아니라 예약 점검을 중단한 결정이다.
새 예약 작업은 생성하지 않았다.

## 실제 검색 성과의 해석

Chrome에서 `sc-domain:otw-schedule.info`를 직접 조회했다. 웹 검색과 생성형 AI
보고서는 모두 **3개월** 선택 상태이며, 표시된 데이터 범위는 **8/1~10/10**,
최종 갱신 표시는 확인 당시 **7시간 전**이었다.

- 웹 검색: 총 91클릭·4,772노출, CTR 1.9%, 평균 게재순위 7.9.
- 검색어 `오버더월`: 3,976노출·27클릭. 전체 노출의 약 83.3%이므로 브랜드 검색
  비중이 크다. 총 클릭과 검색어 표 합계는 익명화·집계 범위 때문에 동일하다고
  가정하지 않는다. 평균 게재순위도 모든 검색어의 동일 순위를 뜻하지 않는다.
- 생성형 AI 기능: 총 노출수 **26**. 페이지별 표는 홈 26, 멀티뷰 2를 표시한다.
  속성 총계와 페이지별 수치를 임의로 합산해 총 28회라고 보고하지 않는다.
  일별 표에서도 10/8·10/9·10/10에 노출이 있어 과거 기록만으로 추정한 수치는 아니다.
- 이는 실제 Google AI 검색 노출의 증거다. 특정 답변의 내용 정확성, 클릭·전환,
  ChatGPT·Claude 등 다른 서비스에서의 인용, AEO 구현의 인과 효과는 확인하지 않았다.
  멀티뷰는 AEO 대상이 아니므로 해당 노출을 JSON-LD 추가 효과로 해석하지 않는다.

[Google 공식 안내](https://developers.google.com/search/docs/appearance/ai-features)는
AI 검색 노출에 별도 AI 파일이나 특별한 schema가 필수라고 설명하지 않는다.
기존 SEO, 접근 가능한 텍스트, 본문과 일치하는 구조화 데이터가 중요하며,
Google AI의 지원 링크 대상은 색인·스니펫 표시 조건을 충족해야 한다.
현재 검증은 이 기술 기반을 확인한 것이며 전체 페이지의 AI 답변 채택 보증은 아니다.

## 운영 본문·메타데이터 검증

10/13 14:34~14:41 KST의 익명 HTTP 응답과 실제 Chrome 화면을 확인했다.
HTML 원문 검증은 JavaScript 렌더링이나 로그인된 Chrome 세션에 의존하지 않았다.

- 15개 공개 URL 모두 리디렉션 없이 200, 자기 주소 canonical, `index,follow`였다.
  HTTP 홈은 HTTPS 홈으로 301 이동한다.
- AEO 대상 14개: 오늘·주간·공지·VOD·권리·피드와 프로필 8개. 각 문서에 공개 본문과
  JSON-LD가 있다. 프로필 대표 문서의 `Person`과 공식 링크도 확인했다.
- 오늘 일정 8개 항목, 10/12~10/18 주간 일정 56개 항목, 공개 피드 10개,
  VOD 5개 분류 각 5개가 제공됐다. 일정의 미등록 상태도 항목 수에 포함되므로
  56개 방송이 확정됐다는 뜻은 아니다. 공지 0개는 정상적인 빈 공개 목록이다.
- 홈·주간·피드·VOD·권리·대표 프로필 6개에서 HTML과 `/api/site-content`의 section
  내용을 대조해 일치를 확인했다. 공개 피드는 `no-store`이며 공개 정책을 다시 확인한다.
- 피드와 VOD에는 `stale` 및 원문 확인 안내가 있었다. 피드 자료 시각은
  10/13 09:23 KST이며 VOD 분류별 시각은 서로 다르다. CHZZK VOD의 7/23 시각은
  조회한 캐시 중 **가장 오래된 수집 시각**으로, 최신 5개 영상 모두가 7월 자료라는 뜻은 아니다.
  HTML 생성 시각을 자료 최신성으로 혼동하지 않아야 한다.
- Chrome의 기존 홈 화면이 정상 표시됐고 주간 메뉴 이동 후 10/12~10/18 화면,
  주간 canonical과 JSON-LD 1개를 확인했다. 추가 AEO 요약 패널은 보이지 않았다.
- Play·관리자·스냅샷의 `noindex`와 익명 `/api/play/catalog` 401을 확인했다.
  Clerk도 현재 `X-Robots-Tag: noindex, nofollow`지만 Google 검색 제외 완료는 아직 아니다.

## 남은 문제와 권장 순서

| 순서 | 문제·영향 | 필요한 후속 판단 |
| --- | --- | --- |
| 1 | 사이트맵 가져오기 실패·발견 0개. XML·현재 Google 검사 요청은 정상이나 보고서 수집 성공은 미확인 | 상태가 변하거나 실제 실패 요청·오류 코드가 생길 때 수동 대조. 근거 없는 재제출·보안 해제·우회 URL 생성은 하지 않음 |
| 2 | 피드 미색인·Clerk 빈 페이지 색인. 유용한 콘텐츠 발견과 인증 주소 정리가 미완료 | 이미 접수한 색인·검증의 결과를 별도로 확인. 접수만으로 완료 처리하지 않음 |
| 3 | 주간·프로필 등 주요 AEO 콘텐츠의 색인·AI 노출 범위 미확인 | 핵심 URL의 개별 검사와 콘텐츠·내부 링크 검토를 우선. 목록에 없다는 이유만으로 미색인이라고 단정하지 않음 |
| 4 | 저장 콘텐츠의 최신성 제한 | 날짜와 원문 링크를 유지하며 수집 신선도를 검토. 생성 시각만 최신이라고 강조하지 않음 |

페이지 색인 보고서의 최종 업데이트 표시는 **10/9**였다. 알려진 6개 주소 중
색인 4개·미색인 2개이며, 미색인은 HTTP 홈의 의도된 리디렉션 1개와 피드 1개다.
Clerk의 내용 없는 페이지 경고는 색인된 4개 안에 포함된다. 이 6개 주소 집계와
사이트맵의 15개 URL은 모집단이 달라서 `4/15`를 사이트 전체 색인율로 계산하지 않는다.
피드와 Clerk 검증 상태는 **시작됨**을 유지했다.

사이트맵 최초 실패 원인은 미확정이다. 10/12·10/13의 실제 Google 검사 도구는
XML 15개를 200으로 가져왔고, 본 호스트의 10/11까지 크롤링 통계는 90일간 1,917건,
HTTP 200 96%, DNS·서버·robots 호스트 문제 없음을 표시했다. 따라서 사이트 전체
크롤링이 막혔다고 판단하지 않는다. 낮은 사이트맵 수요나 Google 내부 재시도·처리
일정은 가능한 설명이지만 **Google 측 지연으로 확정하지 않는다**.

## 검증 범위와 종료

10/13 08:12 Google 검사 요청 로그에서 확인한 운영 Worker는
`b6142795-503d-491e-8ca4-8d06092f68ee`이며 연결된 커밋은
`36737d6001ff3080b7f1c1c2fbfceaf01f643cf4`다. 오후 14:34~14:41의 HTML·API
검사에서는 응답별 Worker 버전을 별도로 기록하지 않았으므로 오전 버전에
귀속시키지 않는다. 이 평가 작업에서는 코드·배포·데이터·보안 정책을 수정하지
않았고 당시 미커밋 멀티뷰 작업을 보존했다.

대표 운영 흐름과 HTTP·API readback을 검증했다. JSON-LD는 실제 응답을 파싱한
결과이며 모든 Google 리치 결과 유형 인증을 의미하지 않는다. 문서만 갱신했으므로
앱 전체 테스트·preflight는 재실행하지 않았다. Core Web Vitals와 모든 역할·모바일
조합, 다른 AI 서비스의 수집·인용·전환은 이번 평가 범위에 포함하지 않았다.

예약 점검은 **삭제 완료**로 종료한다. 사이트맵과 검색 노출 확대까지 완료됐다고
보고하지 않는다. 앞으로의 수동 조사는 별도 필요성이 있을 때 진행한다.
