## 적용한 개선

- YouTube 개발 화면에 `로컬 데이터` 배지를 추가했다. 지연 판정이나 저장 시각을 임의로 정상화하지 않았다.
- X(트위터)·카페는 중복 제목과 설명을 줄이고 상태·예산·실행·소스 표를 밀집 배치했다. 카페의 과거 점검 성공과 현재 확인 지연을 구분하고 주의 게시판은 중복 없이 센다.
- X는 기간 내 작업별 실제 호출 수 차트와 비용 상세를 제공한다. 실제 0, 작업별 내역 미기록, 조회 실패를 구분한다.
- 사용·예약을 포함한 X 예산 점유율과 잔여는 X 수집 화면에서 표시한다. 자원의 X·YouTube 예산 카드는 수집 화면과 동일 API·장부를 표시하는 중복으로 확인되어 후속 정리에서 제거했다. Cloudflare 실제 D1 사용량·공통 쓰기 보호 한도·보존 정책은 서로 다른 정보이므로 유지한다.
- 방송 클립 표는 채널명·ID 검색과 명확한 사용처를 제공하고 공지 기간 입력은 동일 기준선으로 정렬했다.

## 후속 수정·점검 항목

1. **운영 수집 로직 즉시 수정은 불필요:** 현재 장애 근거가 없다. 로컬의 지연을 숨기거나 운영 DB를 로컬로 복사하는 변경도 하지 않는다.
2. **운영에서 재발하면:** 같은 운영 URL·동일 관찰 시각의 다음 확인 / 마지막 성공, 실제 실행 결과, API 할당량, 공통 D1 쓰기 보호 장부를 함께 확인한다. 보호 장부를 조회하기 위해 새 감사 쓰기를 만들지 않는다. 차단된 예약은 실행 자체가 생성되지 않을 수 있다.
3. **별도 승인 릴리스:** 로컬 UI 검증과 운영 배포를 구분한다. 기존 미커밋 API·캐시 폐기 작업의 릴리스 안전 검사와 단계별 마이그레이션은 이번 UI 작업에서 우회하거나 수행하지 않는다.

## 검증 범위

- 관련 UI 회귀 테스트 43개: 소스 검색, 설정 바로가기/포커스, 오류·지연 중복 집계, 실제 0과 미확인, 이전 사용량 보존, 삭제 확인 취소, 공지 기간 제거 후 미저장 보호, 기존 YouTube 실행 접수/종료 구분.
- 애플리케이션 및 테스트/Worker/Node 타입 검사, 아키텍처 검사, 변경 코드 lint, 빌드 통과. 전체 릴리스 preflight는 수행하지 않았다.
- 실제 로컬 관리자 내비게이션으로 1280×900과 390×844 다크 화면에서 X·카페·클립 채널·서비스 예산·공지 게시 기간을 확인했다. 검색, 설정 열기, 수정 진입/취소와 키보드 날짜 이동을 확인했다. 페이지의 가로 넘침 없이 표 내부 스크롤을 확인했다.
- 이번 확인에서는 수집·저장·삭제를 실행하지 않았으며 라이트 테마와 운영 UI의 신규 화면 배포는 확인하지 않았다. 로컬 X의 최근 24시간 호출은 실제 0이므로 비어 있는 그래프를 숫자로 꾸미지 않았다. 값이 있는 차트와 오류 시 이전 값 보존은 회귀 테스트로 보완했다.

## 후속 카드·중복 UI 정리

X 수집·원문 보강 요약은 같은 행에서 동일 높이로 배치하고 예산은 별도 가로 행으로 분리했다. 수치는 20px, 보조 데이터는 13–14px, 레이블은 12px로 구분했다. 반복 설명을 제거하고 관계별 집계·보류 사유·답글 표시 상태는 키보드로 펼칠 수 있는 진단 상세에 보존했다.

자원 화면의 중복 예산 컴포넌트와 전용 테스트·조회 연결을 제거했다. 페이지 제목과 새로고침은 기존 운영 컴포넌트에서 제공하며 실제 D1 계측·공통 쓰기 보호·보존 정책은 유지한다. 관련 3개 파일의 회귀 테스트 22개, 타입·아키텍처·변경 코드 lint·빌드를 검증했다. 로컬 관리자 진입 경로의 데스크톱과 모바일 다크 화면에서 카드 높이, 가로 넘침, 키보드 진단 펼치기, 자원 새로고침을 확인했다. 수집 실행·설정 저장·DB 변경·커밋·배포는 하지 않았다.
