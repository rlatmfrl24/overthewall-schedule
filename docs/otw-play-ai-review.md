공식 영상·노래 클립의 후보 검수 및 URL 직접 등록에서 영상 확인 후 **AI로 자동 채우기**를 실행한다. 전체 영상 또는 지정 구간을 분석한다. 여러 곡이면 곡·구간을 선택한 뒤 미편집 항목을 적용한다. 근거의 영상 시간은 원본 영상 기준이다.

검수 화면에서 요청한 AI 분석이 끝나면 6초간 별도 토스트로 완료를 알린다. 일부 분석과 실패는 다른 메시지로 구분하며, 대기·분석 중·재시도 대기는 완료로 알리지 않는다. 화면에서 진행 중인 작업을 이어서 확인한 경우도 완료 시 알리지만, 이미 끝난 과거 결과를 열거나 같은 결과를 다시 조회하는 것만으로 알림을 반복하지 않는다. 요청 즉시 캐시된 완료 결과를 받은 경우에도 요청 결과를 알린다. 브라우저 푸시나 화면을 떠난 뒤의 백그라운드 알림은 포함하지 않는다.

분석 버튼을 누른 화면에서는 완료 토스트와 함께 짧은 비프음이 한 번 재생된다. 사용자 클릭 시 브라우저 오디오를 준비하며, 소리가 차단되거나 지원되지 않아도 토스트·결과 적용은 계속 동작한다. 과거 완료 결과를 여는 것만으로는 소리를 내지 않는다.

기존 곡 대조는 등록된 곡명·별칭과 원곡 가수의 식별자를 함께 사용한다. 가수의 한글·영문 병기(예: `아이묭(Aimyon)`)도 각각 대조하며, 같은 가수로 해소된 중복 표기는 하나로 처리한다. 여러 곡이 번역 제목 일부를 공유하면 전체 곡명이 일치하는 단일 항목을 우선한다. 여전히 동등한 후보가 여러 개이면 자동 연결하지 않으며, 중복 가능성을 표시하고 검수자가 선택한다. 기존 카탈로그 레코드를 자동 병합하거나 삭제하지 않는다. 저장된 AI 결과도 조회 시 최신 카탈로그로 다시 대조한다.

후보 검수의 `연결할 곡` 옆에 있는 `기존 곡 검색`에서 곡명·별칭·원곡 가수를 텍스트로 검색할 수 있다. 보관된 곡은 제외하며 선택한 기존 곡 ID를 검수 저장에 사용한다. 분석 중 수동으로 선택한 곡은 자동 적용으로 덮어쓰지 않는다.

카탈로그 대조에서 생성한 중복 경고도 매 조회 시 재계산한다. 중복 후보가 정리되면 이전 경고는 제거하고, 모델이 반환한 영상·근거 경고는 유지한다.

기존 검수값, 사용자가 수정하거나 지운 값, 분석 도중 바뀐 값은 자동으로 덮어쓰지 않는다. 항목별 현재/제안 비교와 명시적 적용, 이후 수정한 값을 보호하는 되돌리기를 제공한다. 기존 곡은 제목·별칭·원곡 가수로 대조하며 모호한 경우 직접 선택한다. 기존 곡의 공통 태그는 변경하지 않는다.

`AI 제안 일괄 적용`은 선택한 곡의 적용 가능한 제안으로 기존 입력·수정값을 명시적으로 교체한다. 새 모델 호출이나 검수 저장은 하지 않으며 되돌릴 수 있다. 이전 분석 결과를 다시 열었을 때도 사용할 수 있다. 모호한 곡·인물 연결과 현재 영상 종류에서 지원하지 않는 항목은 제외하며, 새 분석 완료 시의 자동 적용은 기존 보호 규칙을 유지한다.

AI 분석은 별도 작업·제안으로만 저장한다. 채널 승인, 후보 종류 정정, ready 저장, 가창 임시 등록, 게시는 기존 관리자 흐름을 따른다. Ready 저장 시 신규 곡·외부 주체 materialization은 유지한다. URL 직접 등록에서도 AI가 정리한 원곡 정보는 명시적 `song.create` 요청으로 저장하고 참여 역할·MV 분류를 보존한다.

### 기본 분류·멤버·방송 출처 보완

- 장르 기본값은 화면과 분석이 공유하는 `contracts/otw-play-tags.ts`의 K-POP/J-POP/보컬로이드다. 표기 변형과 중복을 통일한다. AI는 이 분류를 우선 사용하며 작품명·커버 언어·가창 형태를 곡 장르와 구분한다. 기본 분류 중 맞는 태그가 없으면 크레딧·영상·음원 근거로 적합한 새 장르 태그 1개를 제안한다. 목록에 없다는 이유만으로 비우거나 기존 분류에 억지로 맞추지 않으며, 장르 자체가 미확인이면 강제로 채우지 않는다. 기존 곡 연결 결과에는 카탈로그의 현재 태그를 사용한다.
- 현재 멤버 전체와 이미 등록된 음악 인물의 공개 이름·별칭을 조회한다. 명확한 멤버 일치는 `subject.kind=member`와 실제 UID로 반환하며, 음악 인물이 아직 생성되지 않은 멤버도 연결한다. 동명·별칭 충돌은 미확인으로 남기고 같은 가창자·역할의 중복을 제거한다. 목록에 없는 외부 가창자는 기존 신규 외부 인물 경로를 유지한다.
- 원본 URL은 해당 가창이 나온 멤버의 **원본 방송 다시보기**다. 설명 또는 영상 근거에 정확한 URL이 있어야 하며, 현재 클립 자체·임의 사이트·채널 홈 주소는 제외한다. YouTube 메타데이터의 방송 여부 또는 등록된 다시보기 채널, CHZZK 재생 메타데이터의 REPLAY 여부와 가창 멤버 채널을 확인한다. 원곡 MV를 방송 출처로 쓰지 않는다. 멤버 연결·출처 확인이 불가능하거나 실패하면 링크만 제외하고 다른 제안은 보존한다.
- 제공된 링크를 검증하는 기능이며 다시보기를 검색해 발견하는 기능은 아니다. 외부 링크를 모델이 직접 방문하지 않는다. 동일 링크는 작업당 한 번 확인하고 최대 3개의 서로 다른 출처를 확인한다. 그 이상 또는 확인 실패는 미확인으로 남긴다. 결과 조회는 출처 API나 Gemini를 다시 호출하지 않는다.
- 현재 프롬프트 버전은 6이다. 결과 계약이 같은 v4/v5는 계속 조회·적용할 수 있고 v1~v3는 재분석을 안내한다. 새 입력 해시에 버전을 포함한다. 영상 분석 범위·1fps·추론 설정은 축소하지 않았다. 모델 입력에서 썸네일·내부 ID·화면 상태를 제외하고 멤버 별칭과 메타데이터 태그의 중복을 제거하며 응답 근거를 간결하게 요청한다.
- 새 곡 제목은 `한국어 제목 (일본어 또는 영어 제목)` 형식을 우선한다. 자료에 명시된 제목과 검증된 alternateTitles로 서버가 표기 순서를 정리한다. 일본어 원제와 영문 로마자 표기가 함께 있으면 일본어를 사용하고 중복 괄호를 제거한다. 한국어 제목을 확인할 수 없으면 임의 번역을 만들지 않는다. 기존 카탈로그 연결 시에는 기존 곡명을 유지하며 Live/Remix 등 실제 버전 표기도 임의로 없애지 않는다.

### 카탈로그 대조와 가창 범위 복원

- 영상 분석 완료 후 서버가 최신 카탈로그를 대조하고 연결 결과를 분석 작업에 저장한다. 조회 시에도 최신 카탈로그로 다시 대조하며 Gemini를 추가 호출하지 않는다. 화면에 기존 곡 연결 완료·복수 후보 선택·신규 곡 초안을 구분해 표시한다.
- 곡 제목의 공백·문장부호, 등록된 별칭, 설명에 실제로 등장하는 다른 언어의 제목을 비교한다. 원곡 가수도 이름·별칭·자료에 명시된 표기를 함께 대조한다. 제목과 원곡 가수가 명확하게 일치하는 하나의 곡만 자동 연결하고, 동명곡·불명확한 아티스트는 선택 후보로 남긴다. Live/Remix 등 버전 표기는 임의로 제거하지 않는다.
- 모델에는 시간을 `MM:SS` 또는 `HH:MM:SS`로 요청하고 서버가 초로 변환한다. `234`를 `02:34`로 추측하지 않으며, 요청 구간 밖 시간은 계속 제외한다. 가창 구간과 완곡 여부에는 각각 영상 관찰 근거를 묶어 반환하도록 하여 근거 누락으로 유효한 제안이 탈락하는 문제를 줄였다. 영상 전체 길이와 곡 전체 가창 여부를 구분한다.
- 기존 저장값·수동 편집값 보호는 유지한다. 기존 결과를 다시 열면 자동 적용하지 않으므로 필요한 항목을 선택하거나 `AI 제안 일괄 적용`을 사용한다. 결과 계약이 호환되지 않는 v1~v3 프롬프트 결과에는 재분석이 필요하다.

## 서버와 운영

### 노래 클립의 전체 영상 구간과 게시

종료 위치를 비운 방송 클립은 등록·가창 수정 시 서버가 재조회한 YouTube 영상 길이를 명시적 종료 위치로 저장한다. 기존 공식 영상의 끝 미지정 동작은 유지한다. 영상 길이를 확인할 수 없으면 임의 값을 넣지 않으며, 게시에는 계속 승인·활성 채널, 재생 가능한 모든 source의 유효한 구간, 가창자 역할과 완곡/일부 가창 확인이 필요하다. 게시 실패 응답은 가창 범위·참여자·source 조건을 구분해 수정 방법을 안내한다.

2026-09-15 로컬 `wum2FhgGljg` 게시 실패는 채널·가창자·완곡 정보 문제가 아니라 `end_seconds=NULL` 때문이었다. 관리자 가창 수정에서 전체 정보 저장 후 서버가 156초로 보정했고, 같은 게시 버튼과 확인 단계로 게시에 성공했다. D1의 performance `9ec97c87-3dd3-4276-938e-57f5fb2c4556`에서 `published`, version 2, 구간 0~156초 및 catalog/read-model revision 38 일치를 확인했다. 전체 공개 설정은 비활성 상태를 유지했다. 기존 같은 상태의 임시 클립은 가창 수정에서 저장 후 게시하면 된다.

- 관리자 전용 `POST /api/play/admin/ai-reviews`, `GET /api/play/admin/ai-reviews/:id`, `GET /api/play/admin/ai-reviews`. 조회는 모델을 호출하지 않는다.
- `music_ai_reviews`, `music_ai_review_requests`, `music_ai_review_attempts`에 작업·멱등 키·호출 시도를 기록한다. 마이그레이션은 `0092_perfect_manta.sql`이다.
- Queue `otw-play-ai-review`, binding `OTW_PLAY_AI_REVIEW_QUEUE`. Worker 분기와 공용 DLQ에 연결된다. ingestion recovery의 cleanup/requeue에서 만료 정리와 중단 복구도 수행한다.
- Gemini Interactions REST API에 공개 YouTube 영상과 제목·설명·태그·메타데이터·공개 멤버 이름/별칭을 제공한다. 내부 검수 메모, 인증 정보, 임의 외부 검색/도구는 제공하지 않는다. `store=false`를 사용한다.
