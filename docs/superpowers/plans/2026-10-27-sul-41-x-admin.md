# SUL-41 X 관리자 개선 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 현재 웹훅 카드의 디자인·오류 의미를 통일하고 기존 $1 공통 예산 안의 REST 복구 필요액/잔여액을 실행 전에 표시한다.

**Architecture:** 기존 XAA 상태 조회와 사이트 snapshot에 읽기 전용 복구 예산 산정을 추가한다. 실제 페이지 크기·비용 추정을 재사용하고 frontend는 동일 query key를 공유한다. 수집·예약·정산·원장 변경은 없다.

**Tech Stack:** React19, TanStack Query, 공용 shadcn Card/Badge, TypeScript Worker, Cloudflare D1/RPC.

**Spec:** [수용 조건과 사용자가 선택한 예산 방식](../specs/2026-10-27-sul-41-x-admin.md).

## Global Constraints

양 사이트 UTC 하루$1·기존 자동충전 유지, 추가 유료 테스트/강제 수집/스키마 변경 없음, 과거 실패·커서·직접 중지·권한 보존. 이전 작업의 로컬 문서 수정은 보존하고 별도 스테이징한다.

## Review Focus

- 초기/재조회 오류와 이전 정상 응답을 혼동하지 않는다.
- 공통 잔여와 사이트 잔여·예약을 함께 반영하며 UTC 날짜가 다르면 확인 불가다.
- 최적화 해제·identity 캐시 없음/만료·추가 페이지에서도 비용 의미가 바뀌지 않는다.
- 이전 peer가 산정 필드를 주지 않으면 호환성을 유지하고 미확인으로 표시한다.
- 최근 표본의 제외·원문 미확보가 완료나 실패0에 숨지 않는다.
