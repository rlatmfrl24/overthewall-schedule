# SUL-47 러브다이아 일간 스케쥴 디자인

## 승인과 의도

2026-11-17 사용자가 간격 보완 V6 시안을 확정하고 실제 러브다이아 일간 화면 적용을 지시했다. 이 문서는 이미 승인된 시안과 기능 보존 조건을 기록한다. 추가 디자인 승인 대기는 없다.

후속 사용자가 누적 전체 리뷰와 `pr-ready`를 요청해 작업 범위의 커밋·게시·PR 생성 및 최종 preflight를 승인했다. 아래 구현 단계의 게시 보류를 대체하며, 병합·운영 배포·운영 DB 변경은 계속 별도 지시가 필요하다.

팬은 두 멤버의 오늘 일정과 실제 방송 상태를 확인하고 치지직 방송으로 이동한다. YouTube·X·프로필 링크도 항상 쉽게 찾을 수 있어야 한다.

## Approaches

- 멤버별 2열: 두 사람의 일정을 같은 비중으로 보여준다. 사용자가 선택했고 이름을 색상 헤더로 이동한 V6 간격 보완안을 최종 확정했다.
- 가로형 요약: 짧게 훑어볼 수 있으나 일정이 많아지면 밀도가 높아진다. 선택하지 않았다.
- 구현자의 선택: 기존 OTW 카드의 공용 동작을 크게 바꾸기보다 러브다이아 전용 표현 컴포넌트를 추가하고 기존 `CardSchedule`·조회·편집 흐름을 재사용한다.

## 화면 계약

- 러브다이아 `/`의 그리드만 큰 2열, 작은 화면은 기존처럼 1열이다. 멤버 ID나 배열의 첫 두 항목을 하드코딩하지 않는다. 과거 날짜의 세 번째 멤버도 기존 공개 정책대로 표시한다.
- 시그니처 색상·실제 프로필 이미지·헤더 이름·상태·YouTube/X·프로필 묶음을 사용한다. 기본 아바타 88px, 이름 28px, 본문 패딩 20px, 일정 간격 12px, 방송 버튼 위 간격 16px다. 모바일은 이름 24px·아바타 64px·본문 16px, 핵심 링크 높이 44px다.
- 두 멤버 이름 행은 상태 유무와 무관하게 같은 높이다. 중복 소속명·장식 설명을 추가하지 않는다.
- 기존 상태 응답 OPEN만 LIVE다. 후속 사용자 피드백에 따라 CLOSE의 오프라인 문구는 생략하며 누락·실패는 확인 불가, 초기 조회는 확인 중으로 표시한다. 오늘이 아닌 날짜에는 현재 상태를 표시하지 않는다. 일정 시간/휴방 여부로 LIVE를 추정하지 않는다.
- 방송 중 카드 배경 클릭과 치지직 버튼은 실제 매핑된 라이브 채널을 연다. 일정 카드는 기존 편집 다이얼로그를 열며 배경 클릭으로 전파되지 않는다. 시청자 수의 기존 접근성을 유지한다.
- 하루 여러 일정은 전부 표시한다. 일정 없음·휴방·게릴라·시간 미정의 기존 구분을 유지한다.
- 기존 사이드바·날짜 이동·일정 추가 메뉴·추가/편집/삭제·이미지 다운로드/복사·시간순 보기·공지·기념일·최종 편집·응원 펫·인증 경계를 보존한다.
- 시청자 수 칩의 호버/포커스 확장·페이드·이동을200ms로 유지한다. 공용 편집 창은 닫히는 동안 표현 모드와 크기를 유지하고 다음 열기에서만 새 모드를 반영한다.
- OTW 일간·주간·스냅샷의 기존 표현과 동작은 변경하지 않는다. 새 패키지·API·마이그레이션·권한/자동화 설정 변경은 없다.

## 검증과 한계

실제 로컬 앱 `/`의 주 흐름을 사용해 러브다이아/OTW·반응형·상태·날짜·프로필/방송 링크·편집 진입·내보내기를 확인한다. 저장 검증은 정상 인증/확인 흐름을 우회하지 않는다. 집중 회귀·타입·lint·구조 검사와 양 사이트 빌드를 수행한다. 원격 DB·유료 AI·자동화 재개·운영 배포·Git 게시/병합은 이번 구현 지시에 포함하지 않는다.

시안 근거는 원본 작업 공간의 `output/sul-47/layout-spacing-v6.jpg`와 `design-qa.md`다. 구현 후 시안과 실제 앱을 같은 크기로 비교하며, 예시 일정/LIVE 표시를 실제 연동 증거로 사용하지 않는다.

## 로컬 적용 결과

승인된 방향으로 구현했고 실제 로컬 `/`에서1440px 2열·모바일1열·프로필·기존 추가/편집·날짜·시간순 보기·다운로드를 확인했다. 모바일 배지 잘림과 아바타 기준선 여백을 보정한 최종 소스/구현 비교는 통과했다. 기능 회귀78건·앱/테스트/Worker/Node 타입·변경 lint·구조·양 사이트 빌드가 통과했다. 실제 CHZZK LIVE 연결은 확인했으며, 검증 일정은 격리된 로컬 D1의 예시 데이터다. 운영 적용을 주장하지 않는다. 상세 근거와 검증 한계는 루트 `design-qa.md` 및 실행 계획에 기록했다.
