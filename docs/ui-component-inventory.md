테스트와 테스트 보조 파일을 제외한 TSX 172개를 조사했다. `src/test/query-client.tsx`는 제품 UI 집계에서 제외했다. 라우트 파일·앱 조합·공통 primitive도 집계에 포함한다.

TypeScript import/export/dynamic import 그래프와 심볼 별칭 해석으로 실제 소스 참조를 확인했다. `index.ts` 공개 인터페이스를 통과하는 참조도 아래 사용처로 풀어 기록했다. 이 표는 정적 참조 근거이며 모든 export의 런타임 실행 빈도를 뜻하지 않는다. `src/main.tsx`는 앱 진입점이다. 나머지 모든 제품 TSX에 소비자가 확인되었다.
