# Mission — 공식 X 대조 변경 읽기

## Why

OTW Schedule의 공식 X 대조 변경을 검토할 때, 각 변경이 운영 비용·복구 시간·누락 방지 중 어디에 영향을 주는지 설명할 수 있어야 한다.

## Success looks like

- 공식 대조의 12시간 주기와 한 차례 대조 안에서의 큐 재개를 설명한다.
- 비교표에서 X 요청 수, 반환 글 수, D1 호출 수의 단위를 읽고 수치의 근거를 찾는다.
- 정상 재개와 예산·장애 복구 사례에서 다음 동작을 예측한다.

## Constraints

- 한국어로 설명한다. 운영 기준, 직전 로컬 구현, 현재 로컬 구현을 비교한다.
- 운영 설정 변경, 배포, 신규 유료 호출은 보류 중이다.

## Out of scope

- 관리자 토글과 아카이브 색인 기능은 이번 비교 범위 밖이다.
