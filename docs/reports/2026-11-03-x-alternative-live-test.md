## 판정

**FxEmbed의 공개 API는 이 PC에서 실제로 작동한다. 개별 글·미디어 보강 후보로 남길 수 있지만, 현재 증거로 웹훅·REST를 모두 대체할 수 있다고 판정하지 않는다. twscrape의 인증 수집 비교는 테스트 계정이 없어 미완료다.**

- 공개 API에서 대상 8명 모두 타임라인 4페이지를 조회했다. 본문·답글·인용·사진·영상·GIF 데이터가 반환됐다.
- 기존 서비스가 공개하는 각 계정 최근 20건, 총160건 중 타임라인에서 발견한 것은155건이다. 미발견5건 중4건은 같은 공급자의 개별 글 조회로는 반환됐다. 따라서 개별 lookup 성공을 신규 글 발견의 성공으로 대체할 수 없다.
- 비교 가능한159건은 작성 시각·첨부 개수·답글 대상 ID·인용 대상 ID가 일치했다. 본문 URL 처리, GIF 유형, 대화 루트 등은 현재 저장 형식과 차이가 있다.
- twscrape는 원본 커밋을 고정해 임시 환경에 설치했다. 사용자는 개인 세션 사용 대신 테스트 계정을 선택했으나 사용할 테스트 계정이 없다고 답했다. 개인 세션은 연결하지 않았다.

## 실제 요청과 기준 자료

11:33:55–11:44:09 KST에 HTTP 요청59건의 상태·시각·소요 시간과 응답을 로컬에 보존했다. HTTP200은56건,204는2건,404는1건이다. 이 중 FxEmbed 데이터 API는49건이다. 이 수치는 가용률 통계가 아닌 이번 제한된 시험의 요청 목록이다.

1. 실제 공개 진입점 `https://otw-schedule.info/api/members`, `https://luvdia-schedule.info/api/members`에서 대상5명·3명을 확인했다.
2. 각 사이트의 기존 공개 `/api/x/posts?handles=...&maxResults=20` 응답을 비교 기준으로 저장했다. 이는 당시 저장된 공개 피드이며 X 원본 전체나 현재 완전한 정답 집합을 뜻하지 않는다.
3. FxEmbed 공개 호스트의 `/2/profile/{handle}/statuses?count=20&with_replies=true`에서 시작해 반환된 `cursor.bottom`으로4페이지씩 실제 조회했다. 로그인·API 키·프록시는 사용하지 않았다.
4. 미발견 글의 개별 `/2/status/{id}`, `since`, 큰 `count`, 첨부 URL을 추가 확인했다.

원본과 실행 스크립트는 git에서 제외되는 [로컬 증거 폴더](../../.tmp/2026-11-03-x-alternatives-live)에 있다. ## 본문·미디어·참조 계약 비교

기존 공개 피드160건 중 타임라인 또는 진단용 개별 조회로 가져온159건을 비교했다.

- 작성 시각159/159, 첨부 개수159/159, 답글 대상 ID159/159, 인용 대상 ID159/159가 일치했다.
- 본문 문자열 자체는101/159만 같았다. 나머지58건은 URL 확장·첨부/인용 링크 제거·HTML entity 처리의 차이가 있었다. URL을 제외하고 공백을 정리하면158/159가 같았고, 남은1건은 `&amp;`와 `&` 차이였다. 따라서 관측한 차이는 임의의 본문 손실 증거가 아니며, URL·링크 메타데이터를 포함해 변환해야 한다.
- `raw_text.text`를 쓰면58건 중31건의 기존 문자열을 그대로 얻을 수 있었으나 나머지는 인용 링크 등의 표현이 달랐다. 무조건 raw 필드 하나를 복사하는 것으로 현재 계약이 완성되지 않는다.
- GIF 한 건은 현재 `animated_gif`, FxEmbed `gif`로 유형이 달랐다. 미디어 ID도 현재 `mediaKey`와 형식이 다르므로 명시적 변환이 필요하다.
- 실제 답글에는 부모 글 ID가 있었지만 이번 타임라인 응답에 대화 루트 `conversationId`는 없었다. 기존 공개 피드에는 부모와 루트가 다른 답글63건이 있다. 부모 ID를 루트 ID로 꾸며 저장하지 않아야 한다.
- 현재 기준 표본의 작성자 지정 `altText`는0건이므로 접근성 설명의 보존 여부를 검증하지 못했다. 편집·삭제·비공개 전환·차단과 장문 전체 보존도 별도 실증이 필요하다.

사진1개·영상1개·GIF1개와 영상/GIF 썸네일2개의 CDN URL을 HEAD로 조회했고 모두200이었다. 사진/썸네일은 `image/jpeg`, 영상/GIF는 `video/mp4`였다. 다중 사진2개의 URL·크기, 영상 재생 주소와 여러 화질 주소도 실제 JSON에서 확인했다. HEAD 성공은 실제 브라우저 표시·영상 디코딩·장기 URL 유효성 검증을 대체하지 않는다.

## twscrape 준비와 중단 경계

- 격리 환경: Python3.13.7, twscrape 원본 `e87459615053aea171178ba19608e63718a85788`(`0.20.1` 표시), Playwright1.64.1. 프로젝트 package/lockfile은 변경하지 않았다.
- 별도 빈 Chrome 컨텍스트의 X 로그인 창을 준비했다. 기존 개인 Chrome 세션에서 로그인 여부만 확인했으며 쿠키를 읽거나 twscrape에 연결하지 않았다.
- 사용자가 테스트 계정이 없다고 답해 로그인 대기 프로세스를 종료했다. 인증된 twscrape 계정 DB는 생성되지 않았다. 해당 대기 프로세스와 직접 자식이 남지 않은 것도 확인했다.
- 빈 계정 풀에서 `NoAccountError`로 즉시 중단되는 자기 검사는 수행했다. 외부 X 요청0회이며 **인증 수집 성공 테스트가 아니다.** [상태](../../.tmp/2026-11-03-x-alternatives-live/twscrape-summary.json), [빈 계정 검사](../../.tmp/2026-11-03-x-alternatives-live/twscrape-empty-pool-check.json)
- 브라우저 도구는 현재 URL을 확인하지 못해 제어를 중단했다. 다른 브라우저 제어로 우회하지 않았으며, 로그인 대기 작업만 종료하고 독립적인 HTTP 검증을 계속했다.

따라서 twscrape와 FxEmbed의 동일 계정·동일 글 비교, 로그인 갱신·제한·연속 운전 비교는 미완료다. 테스트 계정이 준비되기 전 개인 계정 사용이나 새 계정 생성을 대신 실행하지 않는다. [twscrape 고정 원본](https://github.com/vladkens/twscrape/tree/e87459615053aea171178ba19608e63718a85788)

## 서비스 적용 판단과 남은 일

1. **신규 글 발견을 포함한 전체 교체: 현 증거로 채택 보류.** 일부 글이 bounded timeline scan에서 발견되지 않았고, 지연 노출·삭제·중단 복구·장기 가용성은 검증되지 않았다. 504개의 고유 글을 반환한 사실로 이 문제를 덮지 않는다.
2. **이미 알고 있는 글 ID의 미디어 보강: 후속 구현 후보.** 실제 개별 조회와 미디어 주소는 동작했다. 향후 적용한다면 작성자·글 ID·미디어 준비·출처·사이트 허용 범위·삭제 정책을 기존 기준과 함께 검증하고, FxEmbed의404만으로 삭제 처리하지 않는다. 실제 절감액은 아직 없다.
3. **로컬 twscrape 비교: 테스트 계정 필요.** 계정이 생기면 이번 공개 응답과 같은 글 ID·미디어·누락 항목을 대조한다. 현재는 설치 성공을 대체 수집의 성공으로 보고하지 않는다.

기존 [공식 gateway](../../contracts/x-activity.ts)와 [수집기](../../worker/features/x-posts/infrastructure/x-collection.ts), [공개 카드](../../src/features/x-posts/ui/x-post-card.tsx)는 변경하지 않았다. 이 테스트는 실제 외부 수집 응답을 검증한 것이며, 정상 coordinator→Queue→저장→D1 readback→실제 서비스 화면에 대체 데이터가 도달한 구현 검증은 아니다. 해당 연결은 아직 구현하지 않았고, 테스트 결과를 운영 적용 완료로 해석하지 않는다.

공식 유료 X API의 수동 호출, 운영 D1 쓰기, 설정·예산·자동충전·Play/AI 자동화 변경, 커밋·푸시·배포는 수행하지 않았다. 자연 운영 자체가 계속 발생시키는 요청·비용을 이번 테스트의 변경으로 간주하지 않는다. 공개 API의 지속 무료 제공·재표시 허용·정지 위험도 이 단기 시험으로 해소되지 않는다.
