# 기존 미커밋 통합 대조 — 2026-10-19

사용자는 PR171을 최종 검토한 뒤 문제가 없으면 master에 병합하고, 기존 미커밋도 모두 반영하도록 요청했다. 최신 원격 기준은 `acf4d54d906e3371e82cdbea4c369e93c412b22e`, 일정 정책 제품 소스는 `07ccbd75a6e31f5bf23995d2ef9a17edddc69a46`다. 현재 기능과 후속 수정은 유지하며 유효 잔여를 통합한다.

## 전체 목록과 보존

등록된 작업 트리 5개에서 staged·unstaged·untracked를 확인했다. 일정 정책과 startup 작업 트리는 깨끗했다. 나머지 세 작업 트리의 파일과 SHA256을 다시 보존하고 다음과 같이 대조했다. 아래 수는 고유 파일 수가 아닌 작업 트리별 관측 항목이다.

| 작업 트리 | 기준 HEAD | 항목 | 현재 master 동일 | master 과거 blob 동일 | 추가 대조 |
| --- | --- | ---: | ---: | ---: | ---: |
| 원본 | `d27f26a4` | 412 | 140 | 221 | 51 |
| X 복구 | `bf0c8159` | 16 | 9 | 0 | 7 |
| 릴리스 | `e65dd5e4` | 2 | 0 | 0 | 2 |

원본 412개는 기존 409개 WIP와 진입 문서 3개다. 10/16 보존 목록의 412개와 비교하면 411개가 바이트까지 동일하고, 달라진 1개는 로컬 인계 포인터 `docs/current-work.md`다. X의 기존 10개도 바이트 동일하며 나머지 6개는 현재 master와 동일한 생성 문서·routeTree의 줄바꿈/stat 표시다. [기존 독립 리뷰 목록](2026-10-16-uncommitted-review-coverage.csv)의 코드·설정·스키마 396개 항목 전부에서 SHA256 불일치가 없었다.

## 반영과 대체 판정

- 현재 master와 같은 변경은 재적용하지 않는다. 과거 blob과 동일한 코드는 후속 수정·퇴역 여부를 확인하며 옛 파일로 덮어쓰지 않는다.
- 원본의 이전 이관 queue·relay·writer·전용 시험은 [PR161 퇴역](2026-10-16-content-transition-retirement.md) 이후 담당 기능으로 대체됐다. 공개·관리자·공유·최종 저장 경계는 `content-access`, 파일 참조·보존은 `assets`, 일반 일정·Play·AI·수집·복구는 각 기능이 소유한다. 과거 0102~0140과 후속 0141 마이그레이션 이력을 유지한다.
- 기존 리뷰의 미해결 outbox 판정·공유 채널·사라진 X 관계 후처리 결함은 PR162/165 이후 구현과 회귀에 반영됐다. [이전 독립 리뷰](2026-10-16-uncommitted-deep-review.md)의 원본 결합을 복원하지 않는다.
- X의 pending 색인·generation ACK·100건 상한·재시도 기한별 선택은 현재 구현에 존재한다. 이후 추가된 사이트 공개 보호·commit 이후 캐시 무효화·관계 제거 시 MATERIALIZED CTE·편집/삭제 경합 보호와 빈 작업/미래 재시도 비용 회귀를 유지한다. 원본 X 파일로 복사하면 이 보호가 후퇴한다.
- 추가 독립 대조에서도 원본 51개와 X 7개에 새로 반영할 유효 코드나 현재 결함은 발견되지 않았다. 남은 유효 잔여는 릴리스 작업 트리의 카페 수집 완료 기록과 현재 작업 안내 2개다. [실제 수집·저장·화면 기록](2026-10-19-luvdia-cafe-week.md)을 원문대로 포함하고, 현재 문서의 최신 승인·빙하유 일정 정책과 보고서 색인을 연결했다. 원본·X 작업 공간의 파일·HEAD·staged 상태는 변경하지 않았다.

## 최종 검토와 검증 범위

PR171의 독립 최종 리뷰에서 중요한 결함은 발견되지 않았다. API 권한과 수정 전후 날짜/멤버 검사, D1 배치 전후 보호, 수집·후보·휴방·live·재시도, 공개 소비자와 최종일 자정 통과 처리를 추적했다. 관련 단위 5파일·34개와 diff 검사가 통과했다.

제품 소스·설정·스키마·테스트는 기존 검증 HEAD와 같고 추가분은 문서다. 실제 개발 로그인 → 관리자 일정 추가 → 공개 조회와 로컬 D1 동일 ID=3, 양 사이트 build, 타입·lint·구조·로컬 D1 doctor·미러 검사와 2,959개 테스트의 합성 검증 근거를 재사용한다. 이전 전체 preflight의 1개 시간 초과와 변경 없는 대상 파일 71개 재실행 PASS는 [PR171 ledger](https://github.com/rlatmfrl24/overthewall-schedule/pull/171#issuecomment-6259837167)에 구분해 기록했다. 추가한 문서 4개의 로컬 링크 31개와 미러 27개 검사가 통과했다.

이 기록은 운영 재수집·DB 쓰기·자동화 재개 지시가 아니다. 병합·자동 빌드의 최종 commit과 실제 상태는 PR171 ledger를 따른다. LuvDia 수동 배포 및 실제 11월 16일 이후 자연 자동 실행 관측은 이 로컬 검증과 구분한다.
