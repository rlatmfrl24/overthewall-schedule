## 의도와 변경

현재 웹훅 구독 상태와 과거 REST 실행 결과를 별도 표시한다. 최신 REST 실행2852/2853의 `failed/shared_budget_unavailable` 원본은 보존한다. 당시 API 호출·저장·비용은0이며 현재 웹훅 전체 장애로 설명하면 안 된다.

- 대시보드와 X 수집 주 화면에 기존 `/api/x/activity` 읽기 결과를 표시한다. 구독 정상·수신0건은 ‘구독 정상 · 신규 수신 대기’다. 최근 수신 시각과 최근 표본의 저장/대기/실패 건수, 양 사이트 합산 UTC 예산을 구분한다.
- 정기/수동 수집은 ‘REST 누락 복구’와 실행 이력으로 표시한다. Operations의 과거 REST 실패/지연 경고 이름·설명만 REST 범위로 바꾸며 저장 결과나 실패 이력을 정규화하지 않는다.
- 두 진입점 상단 새로고침이 같은 웹훅 query를 갱신한다. 초기 조회 실패·정상 캐시 후 재조회 실패는 ‘최신 상태 확인 불가’이며 캐시는 이전 정보로 명시한다. 상태가 불명확할 때 제어를 막고, 제어 요청 실패 후 재조회하되 변경 요청 자체를 재시도하지 않는다.
- app/admin 조합 계층이 웹훅 카드/경고를 Operations 화면에 주입한다. 새 엔드포인트·스키마·주기 조회·유료 API 경로는 추가하지 않는다.
