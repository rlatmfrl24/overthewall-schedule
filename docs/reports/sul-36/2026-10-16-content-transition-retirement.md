## DB 변경과 복구 조건

`0141_retire_content_transition.sql`은 Drizzle custom migration으로 생성했다. 적용된 0102~0140은 수정하지 않는다.

- 이관 테이블 26개에 한 행이라도 있거나 이관에 연결된 파일 의도가 남으면 적용을 거부한다.
- 아직 실행 가능한 예약 항목의 `continuation_json.transition`도 lane/status 색인을 사용해 확인한다.
- 명시한 트리거 492개만 제거하고, 혼합 트리거에 있던 일반 이미지 참조 처리를 assets 전용 9개로 같은 트랜잭션에서 교체한다.
- 기존 파일 보호 14개, X 최적화 6개의 SQL과 모든 테이블·데이터·제약·이력을 유지한다.
- 관리자·다른 멤버 저장은 유지한다. 정책 경계를 넘긴 수집 응답의 최종 저장은 전체 소유 트랜잭션과 함께 실패한다.

파일 색인이 손상된 경우에도 일반 행 수정이 색인을 복구하던 계약을 유지한다. 이미지 필드 변경 여부만으로 트리거를 생략하는 초기 구현은 실제 회귀 테스트에서 실패하여 제거했다. 관련 없는 참조 1,000개를 추가해도 일반 수정은 읽기 299→303행, 쓰기 1행으로 유지됐다.

운영 적용 직전에는 계정 합산 사용량, 양쪽 잔여 책임, 실제 배포 버전과 background/DLQ metrics를 다시 조회한다. 메시지는 소비하거나 purge하지 않는다. 잔여 책임이 발견되면 강제 완료·취소하지 않고 해당 마이그레이션과 배포를 보류한다.
