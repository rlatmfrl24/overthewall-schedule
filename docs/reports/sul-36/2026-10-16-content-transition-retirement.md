기준 운영 소스: `037d4252278f17950b10be9af8b33a525027a9e6`. 작업 브랜치: `codex/content-transition-retirement`.

## DB 변경과 복구 조건

`0141_retire_content_transition.sql`은 Drizzle custom migration으로 생성했다. 적용된 0102~0140은 수정하지 않는다.

- 이관 테이블 26개에 한 행이라도 있거나 이관에 연결된 파일 의도가 남으면 적용을 거부한다.
- 아직 실행 가능한 예약 항목의 `continuation_json.transition`도 lane/status 색인을 사용해 확인한다.
- 명시한 트리거 492개만 제거하고, 혼합 트리거에 있던 일반 이미지 참조 처리를 assets 전용 9개로 같은 트랜잭션에서 교체한다.
- 기존 파일 보호 14개, X 최적화 6개의 SQL과 모든 테이블·데이터·제약·이력을 유지한다.
- 관리자·다른 멤버 저장은 유지한다. 정책 경계를 넘긴 수집 응답의 최종 저장은 전체 소유 트랜잭션과 함께 실패한다.

파일 색인이 손상된 경우에도 일반 행 수정이 색인을 복구하던 계약을 유지한다. 이미지 필드 변경 여부만으로 트리거를 생략하는 초기 구현은 실제 회귀 테스트에서 실패하여 제거했다. 관련 없는 참조 1,000개를 추가해도 일반 수정은 읽기 299→303행, 쓰기 1행으로 유지됐다.

운영 적용 직전에는 계정 합산 사용량, 양쪽 잔여 책임, 실제 배포 버전과 background/DLQ metrics를 다시 조회한다. 메시지는 소비하거나 purge하지 않는다. 잔여 책임이 발견되면 강제 완료·취소하지 않고 해당 마이그레이션과 배포를 보류한다.

## 검증 기록

- 실제 운영 OTW Worker 번들의 SHA-256: `93053eb5bde38fa03b0a28fdf6a9b6ab0cf8d7e08004d06b2168ee4c8aef5167`.
- 격리된 실제 Miniflare D1에서 이 번들의 스키마 140/141 일정 저장·조회와 스키마 141 관리자 공지 저장을 확인했다. 새 Worker도 같은 DB에서 같은 HTTP 경로로 저장·조회했다.
- 이관 책임이 있는 경우 적용 거부, 중간 DDL 실패 시 기존 트리거 전체 복원, 기존 원본·참조 보존을 확인했다.
- 초기 로컬 적용 비용: 502 statements, 읽기 353,040행·쓰기 9행. 원격 예산 판단에는 양 사이트 합계와 여유를 더한다.
- 일반 기능 D1 검증 69개 통과. X 빈 작업 11행·미래 재시도 7행 기준을 유지했다.
- 이관 전용 테스트 중 파일 보호·업로드 불명확성·롤백·동시 변경·과거 조회·정각 차단 사례는 담당 기능에 남겼다. 제거된 이관 실행 계약만 검증하던 사례는 실행부와 함께 제거했다.
- 테스트의 전체 과거 SQL은 변경하지 않고 압축해 전달한다. 기능별 DB, 전체 스키마 업그레이드, 실제 Workflow 프로젝트를 모두 전체 검증에 포함한다.

최종 전체 검사와 운영 적용 결과는 이 변경의 PR 검증 기록에 정확한 HEAD·마이그레이션·Worker 버전과 함께 기록한다. 이전 실패한 검사나 런타임 시작/종료 오류를 통과로 계산하지 않는다.
