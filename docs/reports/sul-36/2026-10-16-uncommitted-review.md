# 2026-10-16 전체 미커밋 리뷰와 PR 대기

후속: 이전에 독립 검토하지 않았던 코드·설정·스키마396개 관측 항목의 변경 hunk·논리 변경을 [추가 독립 리뷰](2026-10-16-uncommitted-deep-review.md)에서 검토했다. 아래는 첫 리뷰 당시 기록이며 현재 결함 수정·검증 대기는 후속 기록을 따른다.

## 결론과 현재 허용 범위

세 작업 트리의 미커밋 변경을 목록화하고 운영 기준과 대조했다. 개인 절대 경로에 의존한 인계 진입점을 수정하고, 퇴역 이관 메서드의 불필요한 테스트 mock 5줄을 제거했다. 아직 병합되지 않은 독립 점검 Worker와 문서 정리를 PR로 준비한다. **사용자 최종 답변은 “D1 중단 유지, PR까지 준비하고 병합 대기”다.** 병합·배포·D1 검사는 하지 않는다.

원본 변경을 최신 master에 통째로 적용하지 않는다. 이미 반영된 X 최적화나 공개 경계를 옛 버전으로 덮고, 제거한 이관 실행부를 되살릴 수 있기 때문이다. 기존 데이터·마이그레이션·원본 WIP·X 작업 트리는 보존한다.

## 고정 기준과 전체 범위

사용자가 지정한 범위는 모든 미커밋이다. 따라서 각 작업 트리의 고정 HEAD에 대한 `git diff HEAD --`와 untracked 파일을 사용했다. 커밋 범위 리뷰로 바꾸거나 빈 `HEAD...HEAD`를 사용하지 않았다. 비교 기준 운영 소스는 `origin/master`의 `462779cf1db6b7e06fadc46d0dc3f878762e241b`다.

| 작업 트리 | 고정 HEAD | 실제 변경 항목 | 대조 결과 |
| --- | --- | ---: | --- |
| 원본 프로젝트 | d27f26a4628dff34b9eb06628b957b26c3b3aa11 | 412 | 운영 blob 동일 173, 이전 병합 이력의 blob 동일 184, 이후 운영 구현과 차이 37, 운영에 경로 없음 18 |
| publication-release | 462779cf1db6b7e06fadc46d0dc3f878762e241b | 71 | 기존 미커밋 보고서 3개와 문서 정리·이동·새 진입점. 수정 시작 전 기준 |

합계 493은 작업 트리별 관측 항목 수이며 고유 파일 수가 아니다. CRLF/stat 차이만으로 dirty로 표시된 항목은 실제 diff와 구분했다. staged 변경은 없었다. 원본 412는 기존 409개 WIP에 직전 문서 작업의 README·AGENTS·인계 포인터 3개를 더한 값이다.

원본에서 운영에 없는 18개 중 신규 유효 잔여는 독립 점검 Worker 4개와 로컬 인계 포인터다. 나머지는 삭제된 이관 실행부·writer·전용 시험이다. 이전 이력 blob 184개는 현재 코드로 다시 병합하는 대상이 아니다. 이후 달라진 37개는 schema-only doctor, 최종 공개 저장 차단, 정상 저장 책임 분리, AI 이관 복구 분기 제거, 시험 계약 및 설정의 후속 변경과 대조했다.

전체 파일의 목록·동일성·잔여 분류를 확인했다. 공개 요청/관리자 → 담당 기능 → 저장 경계, Queue 조정 → item outcome → 재시도, 파일 공유/보존, X pending/generation 경계를 정적으로 추적했다. **퇴역 실행부 전체와 이미 반영된 모든 대형 파일을 이번에 줄 단위로 독립 재검증했다는 뜻은 아니다.** 이미 검토·병합된 동일 소스는 PR160·161의 검토 근거를 재사용하고, 현재 차이와 소비 경계를 확인했다.

## Standards

**S1 / P2 / 수정:** 원본 `docs/current-work.md`의 유일한 인계 링크가 개인 `C:/Users/...` 작업 트리를 가리켰다. 다른 clone·GitHub·장비에서 현재 지시를 읽을 수 없어 Documentation Hygiene 및 자연스러운 진입점 요구를 충족하지 못했다. PR에는 저장소 내에서 완결되는 본문을 두고, 원본 로컬 포인터는 저장소 웹 문서로 연결했다. 개인 경로는 당시 WIP 보존 위치라는 증거로 한정했다.

Standards 발견 1건, 미해결 0건. 가장 큰 문제는 S1이었다.

## Spec

**R1 / P2 / 수정:** “남은 작업들은 내일 진행할 수 있게 문서로 정리”, “당장 남은 작업에 대해서만 작업에 참조”해야 하나, S1의 절대 경로와 특정 작업 트리를 유일 재개 위치로 지정한 문구 때문에 다른 환경에서 인계가 끊겼다. 저장소 자체의 README → current-work 흐름으로 정리하고, PR 대기와 운영 버전을 구분했다.

공개 시각·대상 세 멤버·D-day 4/9/10/11, 최종 batch 양끝 guard, 공유 파일 참조, X pending/generation 및 현재 scope 검사에서 새 계약 위반은 확인하지 못했다. CHZZK 9004 수정은 미구현 후속 작업이며 이번 diff가 해결했다고 보고하지 않는다.
