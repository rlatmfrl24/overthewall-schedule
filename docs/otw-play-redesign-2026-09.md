# OTW Play 3색 전면 개편 — 활성 구현 명세

2026-09-07. 사용자 승인 계획이 기존 공개·회원 UI 배치 지침보다 우선한다. 관리자 운영 UI, 공개 설정, 서버 API, DTO, DB는 이번 개편 대상이 아니다.

## 제품 구조

공통 사이트 사이드바·모바일 헤더 → Play 내비게이션 → 독립 스크롤 콘텐츠 → 실제 높이를 차지하는 하단 영상 콘솔.

| 진입 | 행동 | 실제 결과 |
| --- | --- | --- |
| 발견 /play | 대표 가창 재생, 다음 후보, 최근 곡 더 보기 | 첫 응답 앞 8곡에서 대표 1개·보조 최대 3개를 수동 전환. 기존 cursor 조회 |
| 곡 탐색 /play/songs | 헤더 검색, 관계 전환, 상세 필터, 버전 펼침 | URL 검색 조건과 기존 catalog query 공유. 한 곡의 실제 detail query 가창만 펼침 |
| 멤버 /play/members | current member 선택 | member와 participantRole=vocal로 기존 카탈로그 조회. noindex, sitemap 제외 |
| 곡 상세 /play/songs/$songSlug | 가창 비교, 공식·대체 영상 선택 | 기존 performance 직접 링크와 소스 선택·재생 계약 유지 |
| 곡 제안 /play/submit | 영상 확인 → 곡·참여자 → 검토·제출 | 기존 preflight, draft, idempotency, edit expectedVersion 유지 |
| 내 제안 /play/submissions | 상태·상세 조회, 수정·철회 | 기존 회원 조회·mutation·충돌 처리. 모바일 상세와 목록 전환·포커스 복원 |

추정 전체 수, 인기, 취향 추천, 좋아요, 저장형 플레이리스트를 추가하지 않는다. 멤버별 데이터가 없으면 빈 결과를 명시한다.

## 색상·시각 기준

브랜드 원본은 src/index.css의 --otw-1/2/3이다. play-design.css에서 행동·선택·텍스트·표면 토큰을 파생하며 메뉴·선택창·볼륨·회원 대화상자 포털에도 otw-play-theme를 적용한다.

- 코랄 #F66479: 주요 재생·제출. 원색 위 #171717.
- 틸 #31A4A9: 활성 내비게이션·필터·멤버·진행률. 밝은 표면 위 글자는 어둡게 파생한다.
- 오렌지 #FFB14E: 발견 그래픽·따뜻한 그라디언트.
- 라이트·다크의 중립 표면과 의미 색상은 분리한다. 멤버 고유색은 신원 표시에만 사용한다.
- 원본 영상 썸네일은 object-contain. 가창 버전 개수 칩으로 곡을 장식하지 않는다.
- 발견 비대칭 보드·굵은 제목·코랄/오렌지 그라디언트, 얕은 버튼 눌림, 내비게이션/콘솔 유리 표현, 절제된 3D 음악 그래픽을 사용한다.
- 화면 진입 240ms, 상태 변화 약 160ms. prefers-reduced-motion에서는 애니메이션·전환·눌림 이동을 해제한다. 가짜 파형은 없다.
- 그래픽: public/images/otw-play/music-sculpture.webp. 생성한 투명 3D 음표이며 실제 곡·멤버 이미지와 구분되는 장식이다.

## 플레이어와 경계

1280px 이상: 하단 232px 콘솔. 실제 영상 356×200px, 곡·참여자·게시 채널·실제 진행률·이전/재생/다음·반복/셔플/볼륨·상세/YouTube. 큐는 콘솔 바로 위 독립 패널이며 영상을 덮지 않는다. 현재 곡이 없으면 큰 콘솔은 생략하고 헤더 큐 진입을 유지한다.

640–1279px: 재생 시 전체 감상 화면. 탐색 복귀 시 같은 iframe이 200×200px로 보이는 미니플레이어로 바뀌며 재생을 이어간다.
640px 미만: 탐색 복귀 전에 일시정지, 재진입 버튼 제공. 전체 화면 키보드 동작과 포커스 복원 유지.

단일 iframe host와 player provider는 공개 경로 전환 밖에 둔다. 큐 중복 방지, 순서 이동, 삭제, 반복 꺼짐/전체/한 곡, 셔플, 볼륨, seek, 복원 계약을 유지한다. 게시 채널을 가창자와 혼동하지 않는다. 회원 인증 경계를 넘을 때 플레이어를 정리하고 세션 큐를 보존한다. 공개 감상 화면으로 돌아와도 자동 재생하지 않는다.

## 검증 기록

- 기존 작업의 원본 썸네일 보존·반복 라벨·게시 채널 구분 의미를 반영했다.
- 최종 preflight 통과: 구조, 테스트 타입, 린트, 단위 233파일/1,590개, Worker 통합 23파일/220개, 커버리지, 빌드, 로컬 D1 doctor, mirror 16파일/0 drift.
- 마지막 큐 삭제 포커스 수정 후 플레이어 11개 회귀 테스트와 린트를 추가 통과했다. 삭제 → Escape → 큐 열기 버튼으로 초점 복원도 실제 브라우저에서 재확인했다.
- 커버리지: statements 80.01%, branches 66.95%, functions 83.46%, lines 81.54%.
- 실제 YouTube 재생 → 곡 탐색 → 버전 펼침 → 멤버 선택에서 widget2 iframe 및 시간이 이어짐을 확인했다. URL member=7, participantRole=vocal과 하네의 실제 1곡 결과가 일치했다.
- 검색어 팬서비스가 URL q와 실제 1곡 결과에 반영됐다. 검색 debounce, URL 복원·초기화 및 모든 기존 필터 의미는 회귀 테스트로 확인했다.
- 큐 추가·중복 방지, 수동 순서 이동·삭제, 전체/한 곡 반복, 셔플, 실제 seek 60초→61초 및 볼륨 35% 표시를 확인했다.
- 1280×720 라이트 콘솔에서 영상과 대기열의 비겹침, 768×1024 미니플레이어 host 200×200 및 같은 iframe, 390×844 전체 감상→일시정지 후 탐색 복귀, 1920×1080 다크 탐색을 확인했다.
- 로컬 회원 UI의 영상 확인 → 곡·참여자 → 검토·제출 → 내 제안 조회 → 수정 저장 → 재조회 → 철회를 완료했다. 제안 7299af7a-f9e1-4de9-b291-cf3f396561b3은 DB 직접 조회에서 status=withdrawn, version=2다. 운영 승인이나 공개 곡 생성은 하지 않았다.
- 실제 주요 버튼 computedStyle: 배경 rgb(246,100,121), 글자 rgb(23,23,23). 색상 토큰 계산 대비: 코랄 5.99:1, 틸 5.99:1, 오렌지 9.95:1. 파생 선택 표면 대비는 아래 계산값을 따른다.
- 동작 축소 CSS 분기와 실패·권한·차단·충돌 처리는 코드 및 기존 회귀 검증으로 확인했다. 모든 화면/크기/테마/장애 상태의 조합을 수동으로 실행했다는 의미는 아니다.
- 브라우저 제어 지연이 발생해 연결을 복구하며 검증했다. 공개 플래그와 관리자 운영 설정은 변경하지 않았다.

파생 선택 표면 대비(토큰의 sRGB 혼합 계산): 라이트 6.43:1, 다크 7.71:1.
